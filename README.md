# Betta Technologies website

## الصور واللغات

الموقع يدعم العربية والإنجليزية عبر زر **English / العربية** في أعلى الصفحة.

لتغيير صورة تطبيق: أنشئي مجلدًا باسم `images` بجوار ملف `index.html`، وضعي الصورة داخله، مثل `my-app.jpg`. بعدها ابحثي في `index.html` عن `App+Screenshot+01` واستبدلي كامل قيمة `src` بـ `images/my-app.jpg`. كرريها مع بقية البطاقات. يفضّل أن تكون الصورة أفقية وبعرض 900 بكسل أو أكثر.

موقع صفحة واحدة جاهز للرفع على GitHub Pages.

## إضافة تطبيقاتك

في ملف `index.html`، ابحثي عن قسم `آخر أعمالنا`. لكل بطاقة تطبيق، غيّري:

- `src` داخل عنصر الصورة: إلى رابط صورة التطبيق أو إلى مسار صورة داخل مجلد الموقع.
- `alt`: إلى وصف مناسب للصورة.
- `اسم التطبيق`: إلى اسم التطبيق الحقيقي.
- الوصف المختصر.
- رابط `href` في زر `عرض التطبيق`: إلى رابط التطبيق الحقيقي على Google Play.

لإضافة تطبيق رابع، انسخي أي كتلة تبدأ بـ `<article class="project-card">` وتنتهي بـ `</article>` داخل `projects-grid` ثم عدّلي بياناتها.

## النشر على GitHub Pages

ارفعي محتويات هذا المجلد إلى مستودع GitHub، ثم من إعدادات المستودع افتحي **Pages**، واختاري النشر من الفرع الرئيسي والمجلد الجذر.

## بيانات التواصل

غيّري البريد الموجود في قسم التواصل: `hello@bettatech.com` إلى بريد الشركة الحقيقي. واستبدلي رقم WhatsApp التجريبي `201000000000` برقم الشركة بصيغة دولية **من دون + أو مسافات**، مثل `201234567890`. بدّلي أيضًا روابط Facebook / Instagram / LinkedIn بروابط صفحات الشركة الحقيقية.
